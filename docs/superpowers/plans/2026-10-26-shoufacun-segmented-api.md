# 收发存三段 API 取数实施计划

**目标：** 月度收发存固定从平台入库、出库 API 获取数据，消除本地同步缺口对月报的影响。

**设计：** 复用 `src/main.js` 的登录、查询条件、API 列映射和 Excel 生成器。将完整工厂月拆为上月 26 日至本月 5 日、本月 6 日至 15 日、本月 16 日至 25 日。依次读取每段入库、出库，在内存中合并，校验表头一致并重新编号；六次取数全部成功后才保存月度 CSV 并生成 Excel。HTTP 错误、缺失列表或不一致表头均终止，不回退数据库或网页导出。正常空列表有效，原始重量精度和重复业务事件保留。

**兼容：** 默认命令和计划任务输出 `YYYYMM收发存报表.xlsx`；旧 `--from-api` 参数仍可用并保留 `_API.xlsx` 文件名。上月结存沿用现有上月报表。日报、数据库同步和独立 API 校对不调整。

**范围约束：** 不运行本月报表生成，不修改现有月报或数据库，不发送消息。移除本次替换后失去调用的收发存数据库生成函数，其他历史代码不清理。

**技术：** Node.js、Playwright、现有 CSV 与 ExcelJS 生成器、`node:test`。
